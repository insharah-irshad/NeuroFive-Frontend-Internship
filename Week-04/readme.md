# Week 04 Multi-Page Website — Portfolio Site with Routing

## Overview

This project is a fully responsive multi-page portfolio website developed as part of the NeuroFive Solutions Frontend Development Internship.
The goal of this task was to create a professional portfolio experience with multiple connected pages, reusable components, dynamic content rendering, and a responsive design that works smoothly across desktop, tablet, and mobile devices.
The website represents my journey as a BS Artificial Intelligence student and showcases my skills, projects, experience, and contact information through a clean and modern interface.

## Pages Included

### Home Page
- Introduction section with personal branding
- Hero section highlighting my AI journey
- Skills preview
- Featured projects section
- Call-to-action section

### Projects Page
- Displays project cards dynamically using JavaScript data
- Each project contains:
  - Project title
  - Description
  - Technologies used
  - Project links

### About Page
- Personal introduction
- Education background
- Technical skills
- Internship experience
- Learning journey

### Contact Page
- Contact information
- Functional contact form
- Client-side form validation
- User feedback messages

## Features Implemented

### Responsive Design
- Fully responsive layout for:
  - Desktop
  - Tablet
  - Mobile devices
- Flexible layouts using CSS Flexbox and Grid
- Optimized spacing and typography for different screen sizes

### Shared Navbar & Footer
A consistent navbar and footer were implemented across all pages.

Instead of repeating the same HTML structure on every page, reusable components were created using JavaScript functions. Each page loads the same navigation and footer structure, which keeps the design consistent and makes future updates easier.

### Dynamic Projects Rendering
The Projects section is generated dynamically from a JavaScript array/object instead of manually writing individual project cards.

This approach improves scalability because new projects can be added by updating the data structure without modifying the HTML layout.

### Contact Form Validation
A client-side validated contact form was implemented without backend integration.

Validation includes:
- Empty field checking
- Email format validation
- User feedback messages after submission
