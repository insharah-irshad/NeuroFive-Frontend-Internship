# Task 2: Animated Landing Page

A modern and responsive fashion landing page built as part of the **NeuroFive Frontend Web Development Internship**. This project showcases an elegant landing page for **IF Atelier**, a fashion brand featuring stylish bags, kurtis, and abayas. The focus was on creating a premium user experience through clean design, smooth animations, and interactive elements using HTML, CSS, and JavaScript.

## Project Overview

IF Atelier is designed to represent a modern fashion boutique that blends timeless elegance with contemporary style. The landing page introduces the brand, highlights its featured collections, and encourages users to explore the products through an engaging and visually appealing interface.

## Features

* Responsive single-page fashion landing page
* Elegant Hero section with call-to-action buttons
* Featured collections for Bags, Kurtis, and Abayas
* Interactive Bento-style layout
* Smooth button and card hover transitions
* CSS Keyframe animations
* Scroll-triggered reveal animations using the Intersection Observer API
* Animated promotional ticker
* Modern typography and clean layout
* Instagram call-to-action section

## Technologies Used

* HTML
* CSS
* JavaScript 
* Google Fonts

## Animation Highlights

This project includes multiple animation techniques to enhance user experience:
* Hover transitions for buttons and collection cards
* Floating hero animation using CSS Keyframes
* Scroll reveal animations powered by the Intersection Observer API
* Smooth animated promotional ticker
Animations were used to improve visual engagement and guide the user's attention without overwhelming the interface. Interactive elements provide feedback during user actions, while subtle motion creates a polished and professional browsing experience.

## Animation Design Decisions

Animations were added only where they improved the user experience and naturally guided attention. Hover effects provide clear visual feedback when users interact with buttons and collection cards, making the interface feel more responsive. The hero animation adds a sense of elegance and movement, while the scroll-triggered reveal introduces content progressively without overwhelming the user. I avoided excessive or continuous animations to keep the landing page clean, readable, and focused on the brand's products.
